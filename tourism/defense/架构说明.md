# 旅策协同 4.2.0 架构说明

```text
工作台/离线页面
  ├─ TaskSchema：v2 校验、v1 保守迁移、稳定 taskHash
  ├─ Knowledge：本地事实检索与引用白名单
  ├─ PlanGenerator：有界、稳定、可取消的候选组合
  ├─ TravelCore：确定性规则、费用与结构化问题
  ├─ TaskState：变更失效、方案选择、交付历史
  └─ Deliverables：接待/营销/产品契约与营销脱敏投影
             │
本机 Agent 服务（令牌 + Origin + 体积限制）
  ├─ 服务端评估快照
  ├─ taskHash + selectedPlanId + confirmationId
  └─ 可选用户模型：需求整理、事实卡回答、内容草稿
```

确定性层不依赖模型。模型不可用或解释失败时，schema、检索、规则报告、候选生成和固定交付模板仍工作。任务变更会使旧确认和交付物过期。外部联网、预订、付款、联系和发布均不属于系统动作。

三个 OpenClaw Skill 分工固定：需求与规划、服务协同、内容与产品；没有新增重复的通用 Agent。
