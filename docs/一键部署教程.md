# 旅策协同 4.2.0 一键部署教程

适用系统：Windows 10/11 x64。主参赛形态是本地 Web 工作台与 Node 本机服务，不要求安装桌面派生运行时。

## 源码包

1. 解压源码包到无特殊权限的目录。
2. 在 PowerShell 进入目录，运行 `npm run check:environment`。
3. 运行 `npm run build:app`。该命令仅从项目源码生成 `dist/app/index.html`，不读取桌面授权构建输入，也不下载依赖。
4. 运行 `npm run start:app`，浏览器会打开本机随机回环端口。
5. 页面右下角“模型设置”可配置用户自己的 OpenAI 兼容模型；不配置也能使用本地咨询、规划、评估与固定模板。
6. 完成后点击页面右上角“退出文旅 Agent”。看到退出提示后可关闭标签页。

## 便携包

双击 `启动旅策协同参赛版.cmd`。便携包自带可再分发的 Node 运行环境，不要求全局 Node。关闭方法同上。

## 离线体验包

双击 `旅策协同-离线体验.cmd` 或直接打开 `tourism/旅策协同-双击体验.html`。离线页禁止业务 HTTP 请求，不能读取模型配置或建立服务端确认，但可演示确定性核心。

## 常见问题

- 页面没有自动打开：复制控制台显示的 `http://127.0.0.1:端口` 到浏览器。
- 模型不可用：先使用固定模板；确认 Base URL、模型名和网络。远程地址必须 HTTPS，本机 Ollama/LM Studio 可用回环 HTTP。
- 端口未释放：回到页面点击退出；若页面已丢失，在启动终端按 `Ctrl+C`。
- 数据会保存在项目吗：任务默认只在页面内存中，离开前需要导出。模型配置仅存当前 Windows 用户目录。

系统不会自动联网核验、联系商户、预订、付款、上传或发布。
