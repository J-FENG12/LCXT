# 8 分钟演示脚本

本稿已按 JBGS-2026-06 和旅策协同 4.2.0 的最终功能更新。完整逐镜头操作、旁白、PPT 页序和失败兜底见 `../../docs/JBGS-2026-06参赛PPT与演示视频流程.md`。

## 时间轴

- 0:00–0:20：作品名、题号、两个核心场景，声明演示数据为虚构。
- 0:20–0:50：双击可携版一键启动，说明本地部署、离线核心和安全边界。
- 0:50–2:05：自然语言需求 → 本地整理草稿 → 字段差异 → 人工应用 → 结构化约束。
- 2:05–2:45：咨询花生排除与交叉接触，展示 factId、来源、日期、状态和模拟标识。
- 2:45–3:55：生成并保留手工方案 → 确定性评估 → 展示费用、步行、兴趣匹配与问题码。
- 3:55–5:05：同步服务端评估 → 人工核对 → 建立确认 → 生成接待执行单。
- 5:05–6:25：预览公开字段 → 切换营销参数 → 营销草稿 → 产品创意 → 人工编辑。
- 6:25–6:55：修改预算使旧确认失效，说明取消与迟到结果隔离。
- 6:55–7:20：Markdown、JSON、打印/PDF 安全导出。
- 7:20–7:40：三个 Skill、三类交付、60/60 回归、25/25 离线评测和 26/26 浏览器检查。

统一演示需求：

> 2 位成人、1 名儿童和 1 名长者，两日游，第一天下午 1 点抵达，预算 3500 元，喜欢非遗和亲子体验，有花生过敏，需要无障碍客房。

演示默认不勾选“使用已配置模型”，以保证无网络环境下稳定完成业务闭环。不得出现学校信息、真实联系方式、账户、API Key 或个人路径；不能把本地测试结果称为主办方验收结果。
