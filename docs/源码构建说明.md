# 源码构建说明

## 主应用链路

```powershell
npm run check:environment
npm run build:app
npm run start:app
```

`build:app` 执行 `build-app.cjs` 和 `tourism/build-demo.cjs`，将源码模块合并为自包含 HTML，并同步需求规划 Skill 的确定性脚本。它不依赖 `node_modules`、不访问网络，也不读取 `build-input/authorized-runtime.bin`。

## 验证

```powershell
npm test
npm run test:browser
npm run test:evaluation
npm run test:live-dry-run
```

前三项分别验证 Node 单元/集成、隔离 Edge 交互与 25 个固定离线业务用例。`test:live-dry-run` 默认真实模型调用为 0。不要在没有明确用量授权时增加 `--live`。

## 可选桌面链路

`npm run build:desktop` 是附加桌面构建，不是源码参赛主链路；它需要开发目录中的授权构建输入和开发依赖。该输入不得发布、编辑或删除，源码包与便携 Web 包均不包含它。

## 目录职责

- `tourism/`：任务 schema、确定性规则、规划、咨询、交付、本机服务和网页界面。
- `runtime/skills/`：三个 OpenClaw Skill。
- `test/`、`tourism/evaluation/`：自动测试和固定评测。
- `docs/`、`tourism/defense/`：部署、技术、答辩与评分证据材料。
- `dist/app/`：由源码生成的 Web 产物，不作为手工编辑源。
