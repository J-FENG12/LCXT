# V5 Agent 优先版讲解说明

适用赛题：JBGS-2026-06 文旅智能辅助场景。材料只使用 V5 项目内容，不出现学校、姓名或真实游客信息。

## 讲解主线

评审给出的场景适配性 30 分和功能实用性 25 分合计 55 分，因此先展示文旅工作人员如何使用 Agent 接单，再展示工作台如何核对游住餐方案与交付材料。部署、代码规范、异常处理和文档证据放在业务闭环之后。

1. Agent 对话入口：描述游客需求，按需选择中文显示的文旅 Skill。
2. 需求核对：模型配置完成时可形成字段草案；工作人员确认前不改任务。
3. 工作台：同一任务下核对事实、候选行程、费用、路线拓扑和约束风险。
4. 局部修改：整体需求、住宿或单个行程项回到对话，提案应用后重新评估。
5. 人工确认：当前任务与选定方案绑定后生成接待执行单。
6. 内容协同：公开字段预览后形成营销与产品创意草稿，人工编辑、安全导出。
