# 演示视频制作清单

V5 提交录制以 `V5提交版讲解视频分镜与旁白.md` 为准。`JBGS-2026-06参赛PPT与演示视频流程.md` 是早期基线，旧测试数字和旧界面描述不可直接照录。

建议 6–8 分钟、1080p，录制前关闭通知并使用虚构任务。

1. 15 秒：作品名、题号 JBGS-2026-06、两个核心场景；不出现学校信息。
2. 60 秒：一键启动、环境自检、无模型可用边界。
3. 150 秒：自然语言需求 → 差异核对 → 逐日/饮食/无障碍约束 → 有据咨询 → 规划与确认。
4. 90 秒：基于同一确认生成接待执行单，指出事实、费用和待核实项。
5. 90 秒：预览公开字段，切换渠道/受众/主题/篇幅，生成并编辑营销或产品创意。
6. 45 秒：展示 Markdown/JSON/PDF 导出、取消与异常提示。
7. 30 秒：三 Skill、严格 schema、25 个固定评测及隐私边界。

录制前检查画面中没有 API Key、用户目录、终端历史、真实联系方式或浏览器账号。若演示模型，应单独取得用量授权，并在剪辑中遮蔽密钥与账户信息。
