# 旅策协同评审交付说明

## 请先看这一页

本作品按赛题要求提交完整源代码、一键部署教程、PPT 和功能演示视频。演示中的“云水古城”、资源、价格和事实卡均为虚构实训数据，不代表真实商家或景区承诺。

## 模型由评委自行接入

- 交付包不包含开发者个人 DeepSeek 或其他模型的 API Key，也不提供公用模型额度。
- 参赛版和桌面演示包使用独立目录 `.tr-ai-review`；首次打开没有已配置的可用模型，不读取开发者调试目录 `.tr-ai-assist`。
- 如需体验模型协同，请在页面“模型设置”中填写评委自己有权使用的服务。远程地址需为 HTTPS；Ollama、LM Studio 等本机回环服务可使用 HTTP。
- 不接入模型也能体验本地事实卡、确定性规划、风险检查、人工确认和固定模板。离线 HTML 是断网兜底，不代表完整桌面桥接能力。

## 三个文旅 Skill

1. **文旅需求规划**（`travel-demand-planner`）：将自然语言整理为字段差异，检索本地事实，生成并校验游住餐候选。人工应用前不修改任务。
2. **文旅服务协同**（`travel-service-coordinator`）：把已确认方案整理为接待日程、核对清单和客服草稿。任务变化后旧确认失效。
3. **文旅内容创意**（`travel-content-lab`）：基于可预览的公开字段生成营销与产品创意草稿，并区分事实、创意和待验证项。

三个 Skill 均随源码交付，目录位于 `runtime/skills/travel-*`，各自包含独立 `SKILL.md`。Agent 界面显示中文名称，英文目录名只作为稳定内部标识。

## 推荐启动顺序

1. Windows 10/11 x64 解压源码包，进入目录运行 `npm run check:environment`、`npm run build:app`、`npm run start:app`。
2. 便捷演示可解压 `desktop-demo`，双击顶层 `旅策协同.exe`。程序未签名，Windows 可能显示常规安全提醒。
3. 从 Agent 对话描述需求并选择对应 Skill；模型未配置时，可进入文旅工作台点击“载入演示”复核离线流程。
4. 关闭桌面窗口可能只缩到托盘；请从托盘选择“退出”。源码 Web 入口可在页面点击“退出文旅 Agent”。

## 能力边界

默认不上传、不联系商户、不预订、不付款、不发布。真实联网搜索需要使用者另行配置和确认；实时路线、天气和地理地图尚未作为已验证交付能力。营销和产品内容均为待人工编辑草稿。
