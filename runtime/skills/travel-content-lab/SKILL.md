# 文旅内容与产品创意

仅接受带当前 `confirmationId`、`taskHash`、`selectedPlanId` 和事实引用的通过方案。任务或选定方案变化后，旧内容保留为历史但标记 `expired: true`。

营销输入使用字段允许清单：目的地、人数规模、明确兴趣、选定方案的公开日程/已知费用、事实引用元数据，以及用户人工填写的渠道、目标受众、主题、篇幅和批准公开补充。请求前必须展示公开字段预览。事实正文默认不进入营销投影；不得发送游客原文、聊天记录、饮食或无障碍原文、个人自由文本、姓名、联系方式、Cookie、密钥或浏览器 Profile。

根据渠道生成不同结构：短视频采用分镜/字幕，公众号采用标题/正文层级，社交平台采用短文案/互动引导。输出标明渠道、受众、主题、篇幅、事实核验项和模拟标识，可人工编辑后导出 Markdown、JSON 或打印为 PDF。

产品创意分三栏：已有事实、基于事实的组合创意、仍未验证的市场/库存/成本/上线项。不得自行声称已有库存、已上线、官方认证、转化率或商业回报。

内容只生成 Markdown/JSON 草稿。未经用户明确授权，不发布、不投放、不上传、不写云文档、不联系商户；网络图片、外部模板和第三方素材默认不使用。
