## 提交前必须由使用者确认

1. 完整源代码、一键部署教程和功能演示视频均为赛题明示提交项，不得只交 EXE。仍需核对主办方最终要求的文件格式、最大容量、PPT 页数、视频时长和命名规则。若有官方样板，把本次 PPT 内容套入样板后再逐页复看。
2. 完整播放并听审已生成的 MP4，重点检查中文语音断句、音量、题号和匿名信息。如果主办方限定时长或要求真人讲解，再按 `docs/V5提交版讲解视频分镜与旁白.md` 剪辑或替换旁白；当前成片不应在未听审的情况下直接上传。
3. 在实际答辩电脑上解压可携 Web 包，运行 `启动旅策协同参赛版.cmd`，从页面右上角点击“退出文旅 Agent”，确认端口释放；不要只关闭浏览器标签。
4. 离线备份可解压 `offline-demo` 包，运行 `旅策协同-离线体验.cmd` 或打开包内 HTML。离线 HTML 不含完整桌面桥接能力。
5. 提交前人工打开 PPT 检查排版，并校对视频片头片尾不出现学校、姓名、邮箱、真实手机号、账号或用户目录。
